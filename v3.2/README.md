# Мир на ниточке — v3.2 · Reference-quality art integration

## Запуск

- GitHub Pages: `/v3.2/`, тест стадий `/v3.2/?demo=1`.
- Локально: из корня `python3 -m http.server 8000`, затем `http://localhost:8000/v3.2/`.
- Автотесты: `npm test` из `v3.2/` (Node 20+).

## Что изменилось

Вместо горизонтальной сцены 752×500 в v3.1 используется вертикальный мастер-фон 941×1672 с художественными тканевыми вывесками, полосой прогресса, карточками улучшений и большой кнопкой. **Это не скриншот-игра**: поверх художественного фона находятся настоящие кнопки, поля прогресса, live-счётчики и один из восьми сменяемых прозрачных арт-объектов.

Восемь игровых стадий: магическое кольцо; первые ряды; готовое туловище; голова; уши; лапки и хвост; собранный кролик без мордочки; готовый кролик. Все новые художественные слои нормализованы в canvas 600×540 и привязаны к фиксированной точке на столе. Сюжетные стадии — **условные игровые иллюстрации, а не достоверная схема вязания**. Статус прогресса — очки, а не реальные петли или ряды.

Механика v3.1 сохранена: клик, idle, два улучшения, офлайн-накопление (8 ч), localStorage, финал, demo slider. Предыдущие прототипы остаются в своих каталогах.

## Архитектура

- `assets/atelier-background.webp` — 941×1672, декоративный фон и подложки под UI, **без надписей и цифр**.
- `assets/stage-00.webp`…`stage-07.webp` — 600×540, согласованный размер canvas, реальные прозрачные слои с отдельными стадиями. Сгенерировано для проекта, выравнивание и оптимизация выполнены отдельно.
- `assets/art-manifest.json` — происхождение и геометрия стадий.
- `index.html`, `styles.css` — компоновка и интерактивные области на процентах.
- `game-engine.js` — расчёты (унаследованы от v3.1), `game.js` — UI, state, переходы, idle/tap/save.

## Оставшиеся ограничения

1. Подложки нарисованы в одном растровом кадре. Это идеально для быстрого соответствия эталону, но не гибко при переводах и изменении компоновки; в финальной игре панели стоит отделить в самостоятельные 9-slice UI-ассеты.
2. Хотя артовые стадии согласованы по цвету и масштабу, **персонаж был изображён отдельно в нескольких AI-кадрах**. Небольшая разница петель и фактуры возможна, особенно на переходах стадий 3–5.
3. В фоновой корзине видны декоративные ушки уже с первой стадии. В следующем проходе эту деталь следует убрать из фонового слоя, сохранив композицию.
4. Оживление — лёгкий jump/bob, не независимые анимированные глаза/уши.
5. Для полноценной Telegram Mini App потребуется бот и надёжная серверная авторизация для социальных и платёжных возможностей; текущий прототип чисто клиентский.
