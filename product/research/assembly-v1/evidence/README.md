# Доказательства внутренней сборочной пробы

Опубликованы по поручению владельца для анализа разработки. **Кандидат получил RETURN; это не игровое демо для приёмки.** Архив содержит выборку исходных кадров и сохранённые наблюдения. Кадры не пересоздавались для публикации и не ретушировались. Полные тексты выводов: [V1](../reviews/critic-v1.md), [V2](../reviews/critic-v2.md).

## Наблюдения и запись

| Файл | Кто и что зафиксировал | Ограничение |

## Художественное сравнение

[Reference-v4 и кадр V1 рядом](reference-comparison.png): две области по 390×844 с промежутком 16 px. Референс 387×620 вписан с сохранением пропорций; игровой кадр 390×844 показан без растяжения. Материал и свет V2 не менялись. Сравнение не является новой утверждённой визуальной базой.

Идентификаторы версий в отчётах относятся к локальным исходникам. Runtime и скрипты проверки не публикуются в этом архиве, поэтому он сохраняет свидетельства, но не является самостоятельным воспроизводимым приложением. Список размеров и SHA-256 опубликованных доказательств: [MANIFEST.json](MANIFEST.json).
