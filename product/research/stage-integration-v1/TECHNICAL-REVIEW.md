## Независимые проверки

Помимо чтения diff выполнен собственный сценарий с двумя изделиями, ручной работой, пассивной пряжей, периодической выплатой, цепочкой конечных событий и лимитом offline 10 секунд. Сценарий не использует авторские тестовые функции.

- **Пауза останавливает только auto-work.** При скорости 3 work/с выключение авто после 3,5 секунды оставило 10,5 work; ручной клик добавил 17. Долгое отсутствие через offline cap не добавило paused work, но завершило реальные события и сохранило их воспоминания. После включения 1,5 секунды дали ровно 4,5 work. Reload сохраняет выбор; paused ETA отсутствует, потенциальная idle-скорость остаётся доступной в read-model.
- **Бесплатный повтор не меняет заработанный мир.** Сорок чередующихся завершений и отмен в одном timestamp дали состояние, точно равное исходному: без расхода пряжи, новых owned/placements, наград, событий или transactionSequence. Попытки начать повтор поверх оплаченного проекта и отменить оплаченный проект через cancelRecraft отклонены.
- **Импорт проверен на настоящем старом формате.** Источник создан движком из `ace8d39^`, а не удалением новых полей из текущего state. Сохранение содержит созданный предмет, размещение, улучшение, активный оплаченный item вне recraft allowlist и ожидающие события. Старый интервал учитывается по прежним скоростям с cap; оплаченная доля переносится на новый бюджет. Дополнительные 500 мс между чтением источника и первым новым tick начислены уже по целевой скорости 1,08 work/с. Мир, таймеры и исходный raw сохранены; запись идёт только в новый ключ; reload в тот же момент ничего не начисляет повторно.
- **Обратный ход часов и разбиение времени.** Импорт при now раньше сохранённого timestamp сохраняет timestamp и долю проекта. Одинаковая последовательность toggle/click с промежуточными tick каждые 127 мс и reload после каждой команды дала то же состояние, что последовательность без промежуточных tick; интервалы этой проверки не превышают cap.

## Совместимость и границы заключения

Опциональные config-поля сохраняют прежнее поведение по умолчанию; старый save без craftAuto читается как auto=true. Новые команды и поля согласованы с `index.d.mts`; схема state остаётся version 2. Rich config migration вызывается явно и не подменяет исторический v1 bridge. Условия повторного изготовления ограничены owned + allowlist + свободная мастерская; обычные оплаченные item/recipe вне allowlist остаются доступны прежнему циклу.

Это **не финальная приёмка UI или удовольствия**. Отдельно остаются реальные четыре проекта и переход между полянками, частичный старый проект вне выбранной четвёрки в UI, темп при максимальных улучшениях, прозрачность/секции/контакт арта, переход к размещению, новый ключ и опубликованный bundle. Незакоммиченные изменения build-static-preview/preview-sources и достижимость pinned commits после merge этим документом не одобряются; их проверят на окончательном commit и CI. Деплой и самостоятельная публикация не выполнялись.
