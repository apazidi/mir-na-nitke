# Отобранные технические доказательства

Новая игра снята директором с собранного runtime `e2b137657278cec06b0f202a861f1a2d7018bfca`, через обычные UI-команды и реальные часы. `v4-player-360/390/430.json` подтверждают оплату четырёх проектов, unlock, pause/return/reload и повтор. Кадры сохранены без перерисовки; это быстрый технический прогон, а не независимое заключение об удовольствии.

`v4-migration.json` и `v4-imported-full-*.png` относятся к отдельному **техническому fixture**: полный старый мир, максимальные улучшения, большой тестовый кошелёк, оплаченный рецепт и фиксированный Date. Такой кошелёк не является заработком свежего маршрута. rAF и клики в этой проверке оставались реальными.

`independent-edge-report.json` — независимые проверки технического ревьюера на предыдущем `5cc9ef5`: старый оплаченный домик, повтор, canvas, удержание кнопки, повреждённый ключ. Двухстрочный pose diff к окончательному `e2b1376` пересмотрен отдельно в TECHNICAL-REVIEW.md; старые edge-результаты не переименованы в новый прогон.

Основной источник проверки — [check.mjs](../../check.mjs), полный изолированный bundle проверяется через `npm --prefix product run check:preview`. Узкий повтор новой ветки: `node product/research/stage-integration-v1/check.mjs` с установленным Playwright. Для публичного URL дополнительно используются HTTPS byte-verifier и GitHub-hosted job; эта папка не заменяет квитанцию доставки.
