# Свободный берег для staged integration

Черновой фон для отдельного технического превью. Создан директором встроенным `image_gen` по workflow навыка `imagegen`; платный CLI/API не использовался.

Причина: арт-аудит обнаружил, что прежний фон Котоутра заранее заполняет сцену крупной колонной, настилом и декором. Новый фон оставляет место изделиям игрока, сохраняя вязаный материал, тёплый свет и узнаваемый пруд справа.

- Edit target: `product/art-experiments/kotoutro-v1/exports/meadow-day.webp` из прежней версии.
- Style/composition reference: `craft-study/assets/meadow.webp`, понравившаяся спокойная полянка.
- [Точный prompt](PROMPT.txt).
- [Исходный output](source/pond-day-v1.png): 941×1672, opaque RGB PNG.
- [Игровой export](exports/pond-day-v1.webp): 1024×1820, WebP quality 92. Только стандартное изменение размера и кодирование; растровое содержание программно не перерисовывалось.

Источник и экспорт сохранены в репозитории; прежние фоновые ассеты не перезаписаны. Финальная художественная проверка учитывает настоящую сцену с предметами, дневной и вечерний режимы и мобильные размеры. Этот файл не объявляет новый baseline или ready-контент.
