# Мир на ниточке · v4.1 Living Meadow

Первая играбельная версия, объединяющая мастерскую и живую полянку **единым сохранением**.

## Играть

- `index.html` через GitHub Pages или любой статический HTTP-сервер (ES modules).
- `?demo=1` — ускоренное изготовление цветка и отдельное тестовое сохранение. Внизу появится сброс демо.

## Что можно сделать

1. Открыть **Полянку**: кролик уже связан в стартовом состоянии этого slice, остальные места пустые.
2. Выбрать **Цветок** и перейти в **Мастерскую**. Вяжется пятью художественными стадиями, без симуляции отдельных петель.
3. Нажимать «Вязать» и приобретать два улучшения — крючок и автоматический клубочек. Idle и офлайн-прогресс (до 8 часов) работают с одним состоянием.
4. Когда цветок готов, **посадить** его на полянке. Это отдельное действие после завершения проекта; растение становится самостоятельным спрайтом.
5. Кролик периодически «нюхает» цветок; можно вызвать реакцию, коснувшись цветка. Короткое касание кролика — приветствие; проведение пальцем или «Погладить» — ласка без прыжка.
6. Переключать день/вечер, смотреть дневник и открывать **Атлас** из двух лоскутов, второй пока закрыт.

## Ограничения честной v4.1

- *Чистая полянка* создана как самостоятельный игровой фон без преждевременно нарисованных дерева/дома/бабочки. Её текстура **более условная и мягкая**, чем арт-эталон v3.2; это визуальное ограничение текущего спринта.
- **Только кролик и цветок** доступны как завершённые проекты. Дерево, домик и бабочка — заблокированные места, не готовые предметы; все они реагируют на нажатие пояснением.
- Для удобства тестирования кролик в этом vertical slice готов сразу. Перенос истории вязания кролика из предыдущих версий **не реализован**: v4.1 имеет собственное сохранение.
- У цветка пять фиксированных состояний, полученных из одного художественного источника; художественная точность этих промежуточных стадий ещё потребует полировки.
- Atlas пока показывает только две плитки: текущая открыта, соседняя недоступна до будущего контента.
- Нет серверной авторизации, мультиустройств, платежей или настоящей постоянной симуляции NPC. События рассчитываются по сохранённому времени визита.

## Структура

- `index.html`, `styles.css`, `game.js`: мобильный UI и взаимодействия.
- `world-model.mjs`: чистая, тестируемая модель экономики, проектов, сохранения и визитов.
- `assets/meadow-clean.webp`: чистый базовый фон без закрытых предметов.
- `assets/rabbit.webp`: спрайт кролика из v4.
- `assets/flower-stage-00.webp` — `flower-stage-04.webp`: пять состояний проекта.
- `assets/flower-meadow.webp`: объект полянки после размещения.
- `assets/atelier-background.webp`: текстильный фон мастерской из v3.2.
- `tests/`: автоматические проверки логики и ресурсов.

