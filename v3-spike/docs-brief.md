# Gate 2 — сравнение art-first с v2

**Цель:** подтвердить, что высококачественная фактура пряжи совместима с активным и автоматическим добавлением материала.

## Проверить на телефоне

1. Открыть `/v3-spike/` на ширине около 390 CSS px.
2. Сразу нажать 5–10 раз — участок вязания должен расти и перестраивать верхний край.
3. Остановиться — то же самое происходит медленнее автоматически.
4. Передвинуть нижний ползунок на 0, 25, 50, 75, 100% и сравнить промежуточные стадии.
5. Купить хотя бы одно улучшение, закрыть вкладку, вернуться — состояние должно сохраниться.
6. Сравнить с корневой v2 по ощущению материала и уюту.

## Не принимать как финал

- Недостаточно показать красивую статическую карточку: должна работать **инкрементальная материализация**.
- Нельзя считать отдельные полосы из фото технологией для выпуска сотен объектов без более универсальной схемы создания ассетов.
- Не добавляем head/ears/paws до подтверждения качества анимации тела.

## Решение после Gate 2

- Если визуально достойно: создать согласованный послойный master всех деталей кролика и полноценную анимацию сборки.
- Если ещё похоже на «растущую фотографию»: сначала сделать 3D/2D rig амигуруми, где верхний край и каждое увеличение числа петель физически связаны с формой и крючком.
