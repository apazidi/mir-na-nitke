# Мир на ниточке — v3 / Art-first stitch experiment

Это **следующий эксперимент после v2**, а не финальная v3. Мы проверяем, можно ли сохранить рабочую механику clicker + idle, заменив простые процедурные петли **фотофактурой настоящего текстильного материала**.

## Онлайн

После публикации в GitHub Pages: `https://apazidi.github.io/mir-na-nitke/v3-spike/`.

Прежняя v2 остаётся по корневому адресу: `https://apazidi.github.io/mir-na-nitke/`.

## Как играть

- Коснись рабочей сцены или кнопки «Вязать!» — добавятся петли к активному ряду.
- В отсутствие кликов петли производятся автоматически; офлайн-прогресс сохраняется (до 8 часов).
- Два улучшения: сила клика и скорость idle.
- Внизу есть **режим быстрого просмотра** 0–100%, чтобы за несколько секунд оценить переходы между стадиями.
- Это **восемь пробных рядов туловища**, не целый кролик. После завершения для полного персонажа пока нет головы, лап, ушей, сборки и оживания.

## Чем это отличается от v2

- Петли и ряды теперь выглядят как настоящая пряжа, а не геометрические векторные элементы.
- Восемь рядов создаются из **одного согласованного художественного источника**, поэтому текстура между соседними рядами не меняет ракурс и не «прыгает».
- На рабочем крае перемещается фотографический текстильный ободок и крючок, привязанные к текущему положению прогресса.
- Все счётчики и улучшения остаются обычным HTML, а не текстом, нарисованным на картинке.
- Существующая v2 нетронута: прототип размещён в отдельной папке.

## Файлы

- `index.html` — минимальная страница для телефона / desktop.
- `styles.css` — текстильно-бумажный UI.
- `game.js` — рендер, игровая экономика, сохранение, события.
- `assets/crochet-body.webp` — прозрачный фотографический мастер детали.
- `assets/open-rim.webp` — отдельный фрагмент открытого рабочего края.
- `assets/crochet-hook.webp`, `assets/yarn-ball.webp`, `assets/stitch-texture.webp` — движущийся крючок, клубок и фактура активных петель.
- `assets/room-ambience.webp`, `assets/left-workbench.webp`, `assets/right-workbench.webp` — окружение.
- `assets/golden-reference.webp` — утверждённый кадр для визуального сравнения, **не часть игрового интерфейса**.
- `tests/smoke.mjs` — проверка механики на Node.js без сторонних зависимостей.

## Запуск и тесты

Открыть `index.html` локально либо запустить статический сервер:

```bash
python3 -m http.server 8000
# перейти на /v3-spike/
```

Проверка логики:

```bash
node --test tests/smoke.mjs
```

## Что НЕ считаем решённым

1. Это **не физически точная симуляция амигуруми**: кусочки фотографического полотна появляются последовательно в отдельных рядовых полосах. Некоторые переходы пока выглядят как художественная условность.
2. Мы пока не получили на выходе независимый художественный master со всеми анимируемыми деталями. Настоящий production pipeline потребует контролируемого послойного 3D/2D-исходника.
3. Внутри ряда петли добавляются на одну видимую сторону; круговое вязание пока упрощено.
4. Сборки кролика, оживания и перехода на полянку нет.
5. Тесты покрывают игровую логику, загрузку ассетов и один кадр рендера в *mock*-Canvas. Полноценное браузерное тестирование и проверку телефоном требуется провести отдельно.

**Gate 2 считается успешным**, если (а) фотографические ряды заметно лучше прежних процедурных; (б) при нажимании видно добавление материала, а не увеличение прозрачности целого кадра; (в) переходы между рядами не раздражают. Если нет — не наращивать количество контента, а улучшать мастер-арт и технологию рядов.
