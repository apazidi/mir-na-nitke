# Мир на ниточке — v3.1 · Stage-based Bunny Slice

**Ссылка после GitHub Pages:** https://apazidi.github.io/mir-na-nitke/v3-stage/

Первая **полноценная играбельная** версия с восемью заранее подготовленными художественными состояниями кролика. Каждый клик увеличивает прогресс, idle вяжет автоматически, а на границах этапов происходит **смена цельного изображения**, без процедурной анимации петель и крючка на основной сцене. Крючок — на большой кнопке «Вязать».

## Что есть

- Восемь стадий: кольцо → первая форма → туловище → голова → уши → лапки → мордочка → готовый кролик с шарфиком.
- Готовая сцена на полянке, короткие анимации UI и открытий.
- Клики, idle, улучшения крючка и клубочка, офлайн-прогресс с ограничением 8 часов.
- Локальное сохранение; восстановление после перезагрузки.
- Режим проверки: добавьте `?demo=1`, чтобы появилась прокрутка восьми стадий и сброс только демо-прогресса.
- Никаких серверных зависимостей, платежей или авторизации Telegram.

## Критическое продуктовое решение

Статика побеждает псевдосимуляцию. В v3-spike красивые ряды пытались воспроизводить процедурно, в результате игра выглядела хуже референса. В v3.1 игрок видит аккуратно подготовленные **восемь качественных картинок**, а клики/idle только приближают следующую. Никакого «проявления» изображения внутри стадии.

## Арт и ограничения

- Восемь изображений сделаны из **одной композиции/контакт-листа**, чтобы сохранить визуальный стиль и один ракурс. Это упрощает art pipeline и предотвращает резкие изменения цвета между кадрами.
- Изображения согласованы художественно, но последовательность изготовления **условная**: голова, уши, лапки появляются уже прикреплёнными к игрушке, хотя настоящая техника амигуруми часто предполагает отдельное изготовление и сборку. Это сознательный выбор для массовой казуальной игры, не учебника вязания.
- Финальная полянка использует отдельное исходное изображение; переход более выразительный, чем точное продолжение кадров мастерской.
- На данный момент кролик оживает через мягкую анимацию сцены, **не отдельный rig с морганием и шевелением ушей**. Перед коммерческим релизом понадобится улучшить это и увеличить исходное разрешение основных кадров для Retina-экранов.
- UI — настоящий HTML/CSS, не встроенный в изображение. Кнопки и цифры управляются игрой.

## Локальный запуск

```bash
python3 -m http.server 8080
# http://localhost:8080/v3-stage/
```

Для локальной разработки с этой папкой как корнем достаточно `python3 -m http.server 8080` и открыть `/`.

## Что попросить оценить у рукодельницы

1. Нравится ли кролик и материалы? Похоже ли это на реальное вязание крючком?
2. Понятно ли, что нажатием приближаешь следующую стадию?
3. Какие переходы выглядят нелогично для человека, который вяжет?
4. Доставляет ли удовольствие получение новой стадии, а после финала — полянка?
5. Что хочется связать следующим?

**Эта v3.1 — прототип для качественного теста, не готовая к монетизации игра.**
