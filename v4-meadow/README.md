# Мир на ниточке v4 · Living Meadow · первый playable slice

## Что это

Отдельный прототип **живой полянки**. Цель — проверить, приятно ли возвращаться к готовому кролику ради наблюдения за его маленьким миром. Пока не добавляем цветок, дерево или домик как игровые изделия.

Показываем **готового кролика для теста**, независимо от прогресса в мастерской. В будущем полянка и мастерская будут использовать общий игровой state.

## Что уже есть

- Сцена полянки с кроликом **отдельным прозрачным спрайтом** из v3.2.
- Спокойное дыхание/покачивание, короткий прыжок на касание, сердечки и реплика.
- Бабочка и небольшие световые эффекты; ручной переключатель день/вечер.
- Сохранение количества визитов, реакций, времени последнего посещения.
- Простая сцена возвращения: если отсутствовал минимум 5 минут, появляется запись о небольшом событии (не постоянная физическая симуляция).
- Переход в существующую мастерскую v3.2 без вмешательства в её сохранения.

## Запуск

```bash
python3 -m http.server 8000
# http://localhost:8000/v4-meadow/
```

## Ограничения

1. **Фон временный.** Он собран из ранее сгенерированного концепта и текстильной подложки. За его пределами остаётся размытое окружение; это не финальный ассет полянки и не «реализация референса один в один».
2. Дерево, домик и мост — художественное окружение концепта, **не полученные в игре изделия**. Для настоящей v4 нужен чистый фон и отдельные спрайты со слотами.
3. Кролик целиковый спрайт: движение ушей и моргание ещё не отделены; пока дыхание и короткий прыжок.
4. События при возвращении — простые детерминированные записи по времени, а не полноценная симуляция поведения.
5. Нет серверного прогресса, Telegram-авторизации, уровней или монетизации. Это клиентский UX-прототип.

## Следующее проверяемое решение

Два коротких теста: (a) интересно ли смотреть на полянку после 1–2 возвращений; (b) достаточно ли пары мягких анимаций для ощущения живого мира. После этого делаем **чистый художественный фон** с четырьмя местами размещения и первый новый объект — цветок.
