# Мир на ниточке — v2: анимация настоящих петель

Небольшой интерактивный этюд, проверяющий **один принцип**: приятно ли игроку наблюдать за тем, как объёмная вещь создаётся из отдельных видимых петель. В отличие от v0.1, здесь **не применяется opacity/fade/mask для появления готового объекта**. Сцена рисует отдельные петли, формирует из них горизонтальные круги и постепенно меняет силуэт туловища амигуруми.

## Запуск

Вариант 1: открыть `index.html` в браузере (без сборки). Вариант 2:

```bash
python3 -m http.server 8080
# Открыть http://localhost:8080
```

Это статический веб-проект, поэтому его можно разместить на GitHub Pages или любом HTTPS-хостинге. Для запуска внутри Telegram Mini App в дальнейшем понадобятся HTTPS и бот, но эта проверка работает без него.

## Что проверяем

- Каждый клик добавляет 8+ реальных «петель» с изменением формы, а не увеличивает прозрачность картинки.
- Туловище растёт из 20 круговых рядов; рабочая нить и крючок следуют за активным стежком.
- Idle-петли добавляются без нажатий; два улучшения ускоряют ручной и автоматический режим.
- Прогресс сохраняется в `localStorage`, офлайн-накопление ограничено 8 часами.
- Нижний ползунок позволяет тестировать любой процент готовности за секунды.
- Справа показан **арт-эталон финального кролика**, но в v2 он пока не является игровым спрайтом: полноценные голова, лапки, уши и оживание — следующий этап.

## Границы / честные ограничения

1. **Этот этюд реализует только туловище**, а не полного кролика из v2-spec. Именно это и было запланировано как первый технический рубеж.
2. Форма здесь процедурная и стилизованная. Для коммерческой игры потребуется заменить примитивы на подготовленные художником анимируемые текстильные спрайты / mesh / puppet-rig, сохранив логику добавления петель.
3. Мы имитируем вязание крючком как визуальное действие, но не физическую структуру петель амигуруми или реальные прибавки/убавки.
4. Клики и idle пока работают без серверной валидации, значения не являются финальным балансом.
5. Для веб-шрифтов подключён Google Fonts с системным fallback. Все остальные компоненты локальные.

## Структура

- `index.html` — интерфейс.
- `styles.css` — адаптивный текстильный UI.
- `game.js` — Canvas2D вязание по петлям, idle/clicker, апгрейды, офлайн-прогресс.
- `assets/bunny-reference.webp` — референс готового кролика (иллюстрация, сгенерированная для проекта).

- `demo.html` — автономная версия для запуска одним HTML-файлом.
- `docs/V2-EXPERIMENT.md` — цели и ограничения эксперимента.

## Что принимать в следующем тесте

1. С первого взгляда понятно, что **петли добавляются**, а не просто растёт полоска.
2. Клик сразу создаёт визуально заметное изменение.
3. Материал ощущается мягким, вязаным и объёмным.
4. Процесс не выглядит механическим заполнением одинаковых пикселей.
5. Возникает желание посмотреть, как эта технология будет работать на голове и ушах кролика.

## После проверки

Если механика нравится, следующий рубеж — полноценный production-quality art pipeline: единый персонаж, отдельные слои тела/головы/ушей, согласованные ракурсы и текстуры, анимация соединения, оживание. После этого снова возвращаем композицию «Кроличья полянка» и долгосрочную idle-прогрессию.
